# Linux 服务器自动部署工具

基于 Electron + Vue 3 + TypeScript 开发的 Windows 桌面应用程序，用于将本地文件夹自动上传到 Linux 服务器并执行权限设置命令。

## 功能特性

- ✅ 服务器配置管理（添加、编辑、删除）
- ✅ 前端/后端双模式部署支持
- ✅ 本地文件夹选择和浏览
- ✅ SFTP 文件上传（支持递归上传整个文件夹）
- ✅ 单文件上传支持（如 .jar 文件）
- ✅ 实时上传进度显示
- ✅ 服务器连接测试
- ✅ 上传后执行自定义 Shell 命令
- ✅ 实时日志查看（支持 tail 命令）
- ✅ 文件拖拽上传
- ✅ 配置信息本地持久化存储
- ✅ 密码和私钥两种认证方式

## 技术栈

- **框架**: Electron + Node.js
- **前端**: Vue 3 + TypeScript + Vite
- **样式**: Tailwind CSS
- **SFTP**: ssh2-sftp-client
- **存储**: electron-store

## 使用说明

### 1. 配置服务器

- 点击"服务器配置"标签页
- 点击"添加服务器"按钮
- 填写服务器信息：
  - 服务器名称
  - 主机地址（IP 或域名）
  - 端口（默认 22）
  - 用户名
  - 认证方式（密码或私钥）
  - 远程部署路径
  - 错误重试次数（可选）
  - 上传后命令（可选，例如：`chmod -R 755 /var/www/html`）

### 2. 测试连接

- 在"文件部署"标签页中选择服务器
- 点击"测试连接"按钮
- 查看连接结果和耗时

### 3. 上传文件

- 点击"浏览"按钮选择本地文件夹
- 确认远程目标路径
- 点击"开始上传"按钮
- 查看上传进度和日志

### 4. 执行命令

- 上传完成后，会自动执行配置的上传后命令
- 命令执行结果会显示在日志窗口

## 配置文件位置

服务器配置存储在本地，路径如下：

- **Windows**: `%APPDATA%/auto-web-upload/server-configs.json`

## 安全说明

- 密码和私钥信息以加密形式存储在本地
- 建议使用密钥认证而非密码认证
- 请妥善保管服务器密钥文件

## 常见问题

### 上传失败

- 检查服务器地址、端口、用户名是否正确
- 确认密码或私钥有效
- 确保远程目录有写入权限

### 连接超时

- 检查网络连接
- 确认防火墙设置
- 验证 SSH 服务是否运行

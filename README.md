# Linux 服务器自动部署工具

基于 Electron + Vue 3 + TypeScript 开发的 Windows 桌面应用程序，用于将本地文件自动部署到 Linux 服务器，支持前端项目和后端微服务的一键部署。

## 功能特性

### 服务器管理
- 服务器配置管理（添加、编辑、删除、导入/导出）
- 密码和私钥两种 SSH 认证方式
- 服务器连接测试

### 文件部署
- SFTP 文件上传（支持递归上传整个文件夹）
- 单文件上传支持（如 .jar 文件）
- 实时上传进度显示（百分比、速度、文件数）
- 上传后执行自定义 Shell 命令
- 文件拖拽上传

### 部署选项（全局设置）

在「系统设置 → 部署选项」中配置，对所有上传入口（手动上传、一键部署、多微服务部署）全局生效：

- **是否上传 sourcemap**：关闭时上传过程自动跳过 `.map` 文件（默认关闭）
- **是否保留已部署 jar 包**：勾选时上传前备份远端旧 jar 包（默认勾选）
- **远端保留 jar 包数**：0-9，上传成功后按时间顺序保留最新 N 个同名 jar 备份，0 表示不清理（默认 0）
- **上传前删除远端 bes 文件**：勾选后每次上传前清理远端目录下的 `bes.*` 文件（默认关闭）
- **部署步骤日志**：上传时「操作日志」面板实时展示部署配置与执行结果（命令 + 操作结果 成对、紫色着色），无操作时显式提示「未执行」，便于审计追溯

### 前端一键部署
- 自动检测产物目录（dist、build、out、public）
- 支持自定义构建命令（npm run build 等）
- 支持自定义环境变量
- 构建日志实时显示，带颜色区分（错误红色、警告黄色、成功绿色等）
- 过滤冗余日志信息（文件列表、computing gzip size 等）
- 进度百分比实时显示
- 构建失败可配置是否停止

### 后端单体一键部署
- 支持 Java Maven 项目构建
- 多种构建命令：clean、compile、package、install、deploy
- 跳过测试选项
- 构建日志实时显示
- 构建产物自动上传

### 后端微服务一键部署
- 自动扫描后端根目录，发现所有 Maven 模块
- 通过 spring-boot-maven-plugin 过滤可部署微服务
- 多微服务批量一键部署
- Maven Reactor Build 模式（同时构建所选模块及其依赖）
- 每个微服务独立显示构建进度和日志
- 部署命令独立配置
- 自定义 Maven 和 Java JDK 路径

### 部署命令显示
- 构建、上传、部署各阶段显示具体执行的命令
- 方便用户了解部署过程

### 终端与日志
- 交互式终端（支持实时输入命令）
- 快捷命令面板（clear、ls、ps 等）
- 实时日志查看（tail -f）
- 日志命令配置
- Java 编译器中文警告编码修复（UTF-8）

### 系统功能
- 深色/浅色/跟随系统 三种主题
- Gitee 版本自动检查更新
- 配置信息本地持久化存储

## 技术栈

- **框架**: Electron + Node.js
- **前端**: Vue 3 + TypeScript + Vite
- **样式**: Tailwind CSS
- **终端**: @xterm/xterm
- **SFTP**: ssh2-sftp-client
- **存储**: electron-store
- **构建**: electron-builder

## 使用说明

### 1. 配置服务器

1. 点击"服务器配置"标签页
2. 点击"添加服务器"按钮
3. 填写服务器信息：
   - 服务器名称
   - 主机地址（IP 或域名）
   - 端口（默认 22）
   - 用户名
   - 认证方式（密码或私钥）
   - 远程部署路径
   - 上传后命令（可选）

### 2. 前端一键部署

1. 选择部署类型为"前端"
2. 选择本地前端项目目录
3. 配置构建命令（默认 `npm run build`）
4. 选择目标服务器
5. 点击"一键部署前端"按钮
6. 查看构建和部署进度

### 3. 后端微服务一键部署

1. 选择部署类型为"后端"
2. 选择架构模式为"微服务"
3. 配置后端根目录（包含 pom.xml 的目录）
4. 点击"扫描微服务"按钮
5. 选择要部署的微服务
6. 配置各微服务的部署后命令
7. 点击"一键部署全部"按钮
8. 查看各微服务的构建和部署进度

### 4. 终端日志

1. 点击"终端日志"标签页
2. 连接服务器
3. 点击"前端日志"或"后端日志"按钮查看实时日志
4. 或在终端中直接输入命令

## 配置文件位置

服务器配置存储在本地，路径如下：

- **Windows**: `%APPDATA%/auto-web-upload/server-configs.json`

## 安全说明

- 密码和私钥信息以加密形式存储在本地
- 建议使用密钥认证而非密码认证
- 请妥善保管服务器密钥文件
